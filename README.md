# KoopMMO resource pack

The resource pack for the KoopMMO Minecraft server (HUD, menus and item art).
The server sends it to players automatically when they join; you don't need to download it yourself.

Direct link used by the server:
https://raw.githubusercontent.com/Koopz8/koopmmo-pack/main/KoopMMO-pack.zip

Updated with each server release.
